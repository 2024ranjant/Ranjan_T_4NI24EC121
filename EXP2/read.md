# Experiment 2: common source amplifier configuration (tsmc 180)
## 1. Aim

#### To design and analyze different Common Source amplifier configurations using TSMC 180 nm CMOS technology in LTspice. The experiment includes simulation and performance analysis of the following circuits:
- Source-Degenerated Common Source Amplifier
- Cascode Amplifier
####  Current-Mirror Loaded Common Source Amplifier
#### The objective is to study their voltage gain, frequency response, and overall amplifier behavior.
## 2. Software Required

#### The following software tools are required for simulation:

- LTspice – for circuit simulation and analysis

- TSMC 180 nm CMOS model library – for MOSFET device modeling
